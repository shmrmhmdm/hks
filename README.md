# 🌿 ഹരിതമിത്രം - പുതുപ്പാടി ഗ്രാമപഞ്ചായത്ത്
### Haritha Mithram Customer Directory & HKS Collection Portal

ഹരിതകർമസേനാംഗങ്ങൾക്ക് പുതുപ്പാടി ഗ്രാമപഞ്ചായത്തിലെ 10,240+ കസ്റ്റമർമാരുടെ വിവരങ്ങൾ അതിവേഗം തിരയാനും (Search), കളക്ഷൻ വിവരങ്ങൾ തത്സമയം ഗൂഗിൾ ഷീറ്റിലേക്ക് രേഖപ്പെടുത്താനും (Collection Log), വാട്സാപ്പ് റിപ്പോർട്ട് ജനറേറ്റ് ചെയ്യാനുമുള്ള വെബ് ടൂൾ (PWA).

---

## 🚀 പ്രധാന സവിശേഷതകൾ (Key Features)

1. **⚡ അതിവേഗ സെർച്ച് (Instant Search):**
   - പേര് (Customer Name)
   - വീട്ടുപേര് / കെട്ടിടം (Building Name)
   - ഡോർ നമ്പർ (Door No)
   - മൊബൈൽ നമ്പർ (Phone Number)
   - QR കോഡ് (QR Code e.g. `PPY-0000969`)
   - കസ്റ്റമർ നമ്പർ

2. **📍 വാർഡ് ഫിൽട്ടർ (Wards 1 to 21):**
   - ഓരോ വാർഡിലെയും വീടുകൾ / കടകൾ മാത്രമായി വേർതിരിച്ചു കാണാം.

3. **👥 HKS അംഗങ്ങളുടെ ലോഗിൻ സിസ്റ്റം:**
   - ഗൂഗിൾ ഷീറ്റിലെ `hks` ടാബിലുള്ള 48 അംഗങ്ങളുടെ വിവരങ്ങൾ.
   - ലോഗിൻ ചെയ്യുന്ന ആളുടെ പേര് ഓരോ കളക്ഷൻ എൻട്രിക്കും ഒപ്പം സ്വയം രേഖപ്പെടുത്തും.

4. **💰 കളക്ഷൻ & പെൻഡിംഗ് തുക മാനേജ്‌മെന്റ്:**
   - **📅 പെൻഡിംഗ് തുക (ഈ മാസം വരെ):** മുൻ കുടിശ്ശിക ഉൾപ്പെടെയുള്ള ആകെ തുക.
   - **💵 ഈ മാസം കിട്ടിയ തുക:** ഇന്ന് നൽകിയ തുക.
   - **⚠️ ബാക്കി പെൻഡിംഗ്:** ആപ്പ് ഓട്ടോമാറ്റിക്കായി കണക്കാക്കും.
   - **🔴 പണം തന്നില്ലെങ്കിൽ:** കാരണം (പൂട്ടിയിട്ടു / ആളില്ല / വിസമ്മതിച്ചു) രേഖപ്പെടുത്താം.
   - **✏️ തിരുത്താനും (Edit) 🗑️ ഡിലീറ്റ് ചെയ്യാനും (Delete) സൗകര്യം.**

5. **📊 കളക്ഷൻ ഡാഷ്‌ബോർഡ് (Dashboard):**
   - ഓരോ അംഗത്തിനും ഇന്ന് / ആകെ ലഭിച്ച തുക, വീടുകളുടെയും കടകളുടെയും എണ്ണം.
   - ഓരോരുത്തർക്കുമുള്ള വ്യക്തിഗത വാട്സാപ്പ് റിപ്പോർട്ട്.

6. **📲 വാട്സാപ്പ് റിപ്പോർട്ട് & ഡിജിറ്റൽ രസീത്:**
   - പ്രസിഡന്റിനുള്ള ദൈനംദിന കളക്ഷൻ റിപ്പോർട്ട് ഒറ്റ ക്ലിക്കിൽ വാട്സാപ്പിൽ അയക്കാം.
   - ഉപഭോക്താക്കൾക്ക് ഡിജിറ്റൽ രസീത് ഷെയർ ചെയ്യാം.

7. **🔄 Google Sheet Live Sync:**
   - ഗൂഗിൾ ഷീറ്റിലെ `Collection` ടാബിലേക്ക് തത്സമയം എൻട്രികൾ സേവ് ആകും.

## 🛠️ സാങ്കേതിക വിദ്യകൾ (Tech Stack)

- **Frontend:** React 18 + Vite
- **Styling:** Modern Vanilla CSS (Mobile-First responsive)
- **Backend / Database:** Google Sheets (via Google Apps Script Webhook)
- **Icons & Animation:** Lucide React, Canvas Confetti

## 💻 ലോക്കലായി റൺ ചെയ്യാൻ (Local Setup)

```bash
# 1. പ്രൊജക്റ്റ് ക്ലോൺ ചെയ്യുക
git clone https://github.com/shmrmhmdm/hks.git
cd hks

# 2. പാക്കേജുകൾ ഇൻസ്റ്റാൾ ചെയ്യുക
npm install

# 3. ഡെവലപ്‌മെന്റ് സെർവർ റൺ ചെയ്യുക
npm run dev
```

## 🌐 ലൈവ് ഹോസ്റ്റിംഗ് (Deploy to Vercel / Netlify)

1. [vercel.com](https://vercel.com) അല്ലെങ്കിൽ [netlify.com](https://netlify.com) തുറക്കുക.
2. ഈ GitHub repository (`shmrmhmdm/hks`) കണക്റ്റ് ചെയ്യുക.
3. Build command: `npm run build`, Output directory: `dist`.
4. Deploy ക്ലിക്ക് ചെയ്താൽ സൗജന്യമായി ആജീവനാന്ത ലൈവ് ലിങ്ക് ലഭിക്കും!
